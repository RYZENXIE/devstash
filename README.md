## 📖 About DevStash

**DevStash** is an all-in-one developer toolbox that solves 4 common daily problems:

| Feature | What it does | Why it's useful |
|---------|-------------|-----------------|
| 📋 **Code Snippets** | Save frequently used code chunks | No more Googling the same syntax again and again |
| 🎨 **Color Palette** | Generate matching color schemes | Instant color combinations for design |
| 📝 **Markdown Cheatsheet** | Live preview markdown while typing | Perfect for writing READMEs & documentation |
| 💡 **Daily Tips** | Get a new dev tip every day | Learn something new daily, boost productivity |

---

## ✨ Features

- ✅ **No Login Required** - Start using immediately
- ✅ **Offline Support** - Works without internet (PWA)
- ✅ **Dark/Light Mode** - Comfortable day or night
- ✅ **Local Storage** - Your snippets and data are saved
- ✅ **Copy to Clipboard** - One-click copy
- ✅ **Keyboard Shortcuts** - Power user friendly
- ✅ **Responsive Design** - Works on mobile, tablet, desktop
- ✅ **Completely Free** - No payments, no hidden charges
